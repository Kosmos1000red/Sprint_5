Тестирование Stellar Burgers с помощью Selenium 

Тесты проверяют регистрацию нового пользователя, вход в аккаунт разными способами (через кнопку входа, личный кабинет, форму регистрации), навигацию между личным кабинетом и конструктором, а также работу вкладок конструктора («Булки», «Соусы», «Начинки»). 

Каждый тест полностью автономен: он открывает браузер, выполняет задачу и закрывает его командой `driver.quit()`. 

Структура файлов 
conftest.py: фикстура драйвера Chrome. 
data.py: URL сайта и константы. 
generators.py генератор почты и пароля.
locators.py: локаторы элементов через 
Директория tests/ содержит файлы со всеми тестами: 
 test_login.py — Вход 
 test_logout.py — Выход 
 test_profile_navigation.py — Переходы ЛК → Конструктор 
 test_registration.py — Регистрация 
 test_constructor_blocks.py — Проверка вкладок конструктора# Sprint_5
